# Design System Builder

Create premium, anti-generic design systems that don't look AI-generated.

## Workflow
1. Run `impeccable` skill FIRST (23 commands clean up spacing/layout/alignment)
2. Run `taste-design` or `design-taste-frontend` to remove AI slop
3. Pick from `awesome-design-brands` (67 real brand design systems) or `awesome-design-html` (115 brand templates)
4. Use `ui-cloner` to match any existing site's design
5. Run `ui-ux-pro-max` for final design intelligence pass

## Rules (NON-NEGOTIABLE)
- Custom icons EVERY TIME — never use stock/Lucide defaults unmodified
- NO borders around icons
- Create BOTH light AND dark mode
- Use real font pairings (not Inter alone)
- Asymmetric layouts — avoid centered everything
- Micro-animations on every interactive element
- Hardware-accelerated transforms only (transform, opacity)
- Color from `color-psychology` module (industry-specific hex codes)
- Test with `impeccable audit` before shipping
